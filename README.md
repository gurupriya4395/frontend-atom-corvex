# ATOM-CORVEX Operations

http://localhost:5173 is the **React** operations desk.

The HTML / CSS / JS copy runs on **http://localhost:5174**.

## Run (React)

```bash
npm install
npm run dev
```

Open **http://localhost:5173**

Stop any old Vite process first (`Ctrl+C`).

## HTML / CSS / JS copy

```bash
npm run dev:html
```

Open **http://localhost:5174**

## Stack

- **UI:** React 19 + Vite 8
- **3D globe:** Three.js
- **Terrain map:** MapLibre GL
- **No backend** — sample events in `src/data.js`
